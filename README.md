One sentence from a house cat, five seconds after sweeping a glass off the table: no apology, no confession, just the most convincing case the cat can make for itself.

Run it locally with `python3 main.py` — it writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
